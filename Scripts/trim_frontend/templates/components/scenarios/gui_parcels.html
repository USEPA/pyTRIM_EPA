AERMOD Receptors

Generate grids of AERMOD receptors using the Receptor Spacing you entered in the editable table above.

Once receptors have been generated, select one of the Download buttons to download a GeoJSON or AERMOD input file of the receptor grids. You can view the generated receptors in the map by turning on the display in the map’s basemap selection box. If you subsequently change receptor spacing, you must again select Generate AERMOD Receptors. If the display in the map does not refresh, select the Recalculate button at the bottom right of the page and again turn on the display in the map’s basemap selection box.
